The split is computed at build time (as a no-JS fallback), then the script below re-applies it using the viewer's current date, so releases move from Upcoming to Released without a rebuild. {%- endcomment -%} {%- if items and items.size > 0 -%} {%- assign today = site.time | date: "%Y-%m-%d" -%} {%- assign sorted = items | sort: "date", "last" -%} {%- capture upcomingRows -%} {%- for release in sorted -%} {%- assign day = release.date | date: "%Y-%m-%d" -%} {%- if day > today -%}{%- include release-row.html release=release day=day -%}{%- endif -%} {%- endfor -%} {%- endcapture -%} {%- capture releasedRows -%} {%- for release in sorted reversed -%} {%- assign day = release.date | date: "%Y-%m-%d" -%} {%- if day <= today -%}{%- include release-row.html release=release day=day -%}{%- endif -%} {%- endfor -%} {%- endcapture -%}
